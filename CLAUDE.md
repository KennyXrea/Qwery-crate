# Qwerty Crate — notes for Claude Code

Geometry Dash friend-group list site. Architecture source of truth: `docs/PLAN.md`.
Build instructions and phases: `docs/BUILD_PROMPT.md`. Where we are: `docs/PROGRESS.md` (read it first).

The owner is a beginner: explain manual steps slowly, one at a time, in plain words, and never ask
them to paste passwords or secret keys into the chat.

## Stack
Vite 8 + React 19 + TypeScript (strict) · React Router 7 (data/library mode, `createBrowserRouter`) ·
Tailwind CSS 4 (`@tailwindcss/vite`, theme tokens in `src/styles/index.css`) · `@supabase/supabase-js` v2 ·
`@tanstack/react-query` · `zod` · Vitest · Supabase CLI (`npx supabase`) · `tsx` for scripts.
Hosted on Netlify (static SPA) + Supabase (Postgres + Auth + Storage). No other libraries without asking.

## Rules
- **All database access goes through `src/api/`.** Components and pages never call `supabase` directly.
- **Never the secret key.** Only the publishable/anon key is used, via `VITE_SUPABASE_PUBLISHABLE_KEY`.
  The secret / service_role key never goes in code, `VITE_` variables, Netlify or git. `.env.local` is git-ignored.
- Security lives in Postgres RLS; frontend route guards are only for the user experience.
- Import zod only from `src/lib/zod.ts` (it turns off zod's `eval()` probe for the CSP; ESLint enforces it).
- No `any`, no `dangerouslySetInnerHTML`, no `enum`s. Named exports. Files that export components export only
  components (React Fast Refresh). Colors only from the theme tokens. Tap targets ≥ 40px.
- Don't use Pointercrate's API/assets/look or RobTop's images. Seed data must be clearly fake.
- **Verify before committing:** `npm run typecheck && npm run lint && npm test && npm run build`.
- **Update `docs/PROGRESS.md` at the end of every phase**, then commit `Phase N: <summary>`.
